# ❤️ Predicción de Enfermedades Cardíacas con Machine Learning

Repositorio basado en el dataset **UCI Heart Disease Dataset** para el análisis, entrenamiento y evaluación de modelos de aprendizaje automático orientados a la predicción de enfermedades cardiovasculares.

---

## 📌 Descripción del Proyecto

Este proyecto desarrolla un flujo completo de análisis de datos y machine learning utilizando el conjunto de datos **Heart Disease UCI**, uno de los datasets médicos más utilizados en clasificación binaria y análisis predictivo.

El repositorio incluye:

- Exploración y limpieza de datos.
- Análisis estadístico y visualización.
- Entrenamiento de modelos de clasificación.
- Comparación de métricas de rendimiento.
- Interpretación de resultados.

El objetivo principal es predecir la presencia de enfermedad cardíaca a partir de variables clínicas y médicas de los pacientes.

---

## 📂 Dataset Utilizado

El proyecto utiliza el dataset **Heart Disease** del repositorio de Machine Learning de la UCI.

### Características principales del dataset

- 303 registros clínicos.
- 13 variables predictoras.
- Problema de clasificación binaria/multiclase.

Variables relevantes:

- Edad
- Sexo
- Presión arterial
- Colesterol
- Frecuencia cardíaca máxima
- Angina inducida por ejercicio
- Resultados ECG
